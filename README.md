# hellos v0.8 - A lightweight system information fetch written in C/Zig.

## Installation

### Using Make
**Dependencies:** `clang`, `make`

```bash
git clone https://github.com/iamadvisory/hellos.git
cd hellos
sudo make install
```

### Using Zig
**Dependencies**: `Zig`

```bash
git clone https://github.com/iamadvisory/hellos.git
cd hellos
sudo zig build --prefix /usr/local
```

## Usage
```bash
hellos
```
